# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Portfolio site for a communication designer (Portuguese-language UI). Built with Lovable and synced to GitHub: do not rewrite published git history (no force-push, rebase, amend or squash of pushed commits), and keep `main` in a working state since pushes sync back into Lovable (see `AGENTS.md`).

## Commands

- `npm run dev` — Vite dev server
- `npm run build` — production build (outputs to `.output`); `npm run build:dev` for a development-mode build
- `npm start` — run the built Nitro server (`node .output/server/index.mjs`)
- `npm run lint` / `npm run format` — ESLint / Prettier
- No test runner is configured.

Both `package-lock.json` and `bun.lock` exist.

## Architecture

- **Stack**: TanStack Start (React 19, file-based TanStack Router) + Vite 8 + Tailwind v4 + shadcn/Radix UI (`src/components/ui`, config in `components.json`) + Supabase. Path alias `@/*` → `src/*`.
- **Vite config** uses `@lovable.dev/vite-tanstack-config` with Nitro (`preset: "node-server"`). The deploy Output Directory must be `.output` (Nitro default), not `build`; `netlify.toml` and `wrangler.toml` both point at `.output/public` / `.output`.
- **Routes** live in `src/routes` (`index`, `about`, `contact`, `auth`, `reset-password`, `admin`, `projects/$id`, `__root`). `src/routeTree.gen.ts` is generated by the router plugin — do not edit by hand.
- **Server entry** (`src/server.ts`) wraps the TanStack server handler and converts swallowed h3 500s into a custom HTML error page (`src/lib/error-page.ts`, `error-capture.ts`). `src/start.ts` registers global middleware: an error-page request middleware and `attachSupabaseAuth` function middleware that forwards the user's Supabase session to server functions.
- **Server functions** (`createServerFn`) such as `src/lib/contact.functions.ts` use `requireSupabaseAuth` middleware, then check admin via the `has_role` Supabase RPC. The contact-reply flow sends mail through Resend; needs `RESEND_API_KEY` (optional `CONTACT_FROM_EMAIL`, `CONTACT_FROM_NAME`).
- **Supabase**: `src/integrations/supabase/` (`client.ts`, `client.server.ts`, `types.ts`) is auto-generated by Lovable — avoid manual edits. Schema changes go in `supabase/migrations/` as SQL files.
